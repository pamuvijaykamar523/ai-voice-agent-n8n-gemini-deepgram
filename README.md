AI Voice Agent using n8n + Gemini + Deepgram

Overview

This project is an AI-powered Voice Assistant built using n8n, Google Gemini, and Deepgram.

Features

- Receives user input through a Webhook
- Generates intelligent responses using Google Gemini
- Converts AI responses into natural speech using Deepgram
- Returns audio through the webhook

Tech Stack

- n8n
- Google Gemini 2.5 Flash
- Deepgram Text-to-Speech
- Webhooks
- HTTP Request
- Postman

Workflow

Webhook → AI Agent → Deepgram Text-to-Speech → Respond to Webhook
